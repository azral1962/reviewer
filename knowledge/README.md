# Knowledge provenance

`SOURCES.csv` is the source registry. Use source IDs in judgments. Register owner insights separately from shared standards. Record title, authority, version/date, location, retrieval date and access limitations. Read mandatory short requirements completely. Retain copyrighted or private inputs only where authorized.

`individual/` records designs and attributed human insight. `collective/` records standards, literature, rubrics, criticism and community decisions. Neither directory determines truth by itself.
